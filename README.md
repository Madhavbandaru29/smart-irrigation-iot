# Smart Irrigation System Using IoT

## Project Overview
The Smart Irrigation System Using IoT is an engineering project designed to monitor soil moisture and automate irrigation. The goal is to help reduce unnecessary water usage and support efficient plant watering.

## Objectives
- Monitor soil moisture levels.
- Automate irrigation based on soil conditions.
- Reduce unnecessary water consumption.
- Explore the use of sensors and microcontrollers in agriculture.

## Technologies Used
- Arduino or ESP32
- C/C++
- Soil moisture sensor
- Water pump and relay module
- IoT technology (planned or implemented features, as applicable)

## How It Works
1. A soil moisture sensor measures the moisture level.
2. The microcontroller reads the sensor data.
3. The reading is compared with a predefined threshold.
4. The system switches irrigation on or off according to the control logic.
